Security Architecture

🔐

bcrypt Password Hashing

All passwords are hashed at cost factor 12 — industry standard, brute-force resistant.

👤

Role-gated Routes

ADMIN role unlocks the CRM and full LMS management. STUDENT role is locked to their own portal only.

🔑

JWT Sessions via NextAuth

Short-lived, server-validated sessions. No plain-text credentials stored anywhere.

🛡️

API-level Auth Checks

Every CRM endpoint re-validates the session server-side — no client-side trust.

🔒

Optional 2FA

TOTP two-factor authentication can be enabled per account for additional protection.

CRM — Sales Pipeline

From first inquiry
to enrolled student.

A purpose-built CRM for coaching programs. No Salesforce bloat. Every feature maps to how your team actually sells.

📌

Kanban Pipeline Board

Visual drag-and-drop board with 5 stages: Lead → Contacted → Qualified → Proposal → Enrolled. Drag cards to advance stage.

⚡

Lead Scoring (0–100)

Automatic score computed from stage, recency, activity count, deal value, profile completeness, and priority. Color-coded badges.

🔍

⌘K Global Search

Instant fuzzy search across all leads by name, email, or company. Keyboard-navigable results with stage + score preview.

👤

Lead Assignment

Assign any lead to a specific admin/rep. Filter the leads list by rep. Per-rep analytics show pipeline and win rates.

📋

Task Management

Tasks linked to leads with due dates, priority, and completion tracking. Overdue tasks surface automatically in notifications.

📎

Activity Timeline

Full audit log per lead: stage changes, tasks completed, notes added, emails sent, and enrichments — timestamped and immutable.

🔖

Saved Filter Views

Save any combination of stage + source + priority + rep filters as a named view. One-click recall — like HubSpot Smart Lists.

🧬

Duplicate Detection

Automatic duplicate check on leads with the same email or name. Warning banner surfaces duplicates for review and merge.

📤

CSV Import

Bulk import leads from any spreadsheet. Intelligent field mapping with preview and de-duplication.

CRM — Automation & Enrichment

The CRM that works
while you sleep.

Automated email sequences, Slack alerts, company enrichment, and proposal generation — reducing manual work to zero.

📧 Email Drip Sequences

  • Build multi-step email sequences with custom delay between steps (Day 0, +3, +7, etc.)
  • Personalization tokens: {{"{{"}}firstName{{"}}"}} auto-replaced per recipient
  • Enroll any lead into any sequence with one click
  • Pause, resume, or cancel enrollments individually
  • Vercel Cron fires at 1 PM UTC daily — sends due emails, advances enrollment steps automatically
  • 3-touch quick-start template built in

🔔 Notification Center

  • Bell icon with live unread count badge (polls every 60 seconds)
  • Notifications for: overdue tasks, enrolled leads, cold leads, new intake submissions, sequences sent
  • Click any notification → navigate directly to the lead
  • Mark individual or all-as-read

✨ Lead Enrichment

  • One-click Enrich button on every lead profile
  • Clearbit autocomplete API fetches company name + logo from email domain
  • Skips personal domains (Gmail, Yahoo, etc.) automatically
  • Auto-enriches company on every new intake form submission — zero manual effort
  • Results cached for 24 hours — no redundant API calls

📄 Proposal Generator

  • One-click proposal at /leads/{"{id}"}/proposal
  • Branded document: program name, tagline, deal value, offer expiry
  • Sections: What's Included, How It Works, Outcome Stats, Personal Notes
  • "Save as PDF" → browser print with @media print — clean, no chrome
  • Proposal defaults (name, tagline, footer) configurable in Settings — no redeploy needed

💬 Slack Alerts

  • Fires when any lead is marked Enrolled — includes deal value
  • Daily cold-lead alert: high-priority leads not touched in 7+ days
  • Webhook URL set via Settings UI — no redeploy needed
  • Rich Block Kit message format with action buttons
